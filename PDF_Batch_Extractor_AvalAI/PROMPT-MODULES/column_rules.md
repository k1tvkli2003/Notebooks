# Multi-Column Layout Rules

## Detection
- Many textbook pages use 2-column layouts
- Columns are separated by a vertical gap or line
- Each column is read independently top-to-bottom before moving to the next

## Rules
1. **Column reading order for RTL documents**: Read the RIGHT column FIRST (top to bottom), then the LEFT column (top to bottom)
2. **Column reading order for LTR documents**: Read the LEFT column first, then the RIGHT column
3. **Do NOT interleave**: Never mix text from different columns in the same paragraph
4. **Column separator**: When transitioning from one column to the next, maintain natural paragraph flow. Do not add artificial separators
5. **Full-width elements**: Headers, footers, or images that span the full page width should be placed in their natural position relative to the column text
6. **Footnotes**: Usually appear at the bottom spanning full width — place them after the column text of that page
