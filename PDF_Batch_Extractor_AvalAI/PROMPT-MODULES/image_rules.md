# Image Detection and Marking Rules

## When You Encounter Images/Figures
If you see any images, figures, diagrams, charts, photos, or illustrations on the page:

1. **Mark each image** at its EXACT position in the text flow using this format:
   {{IMG_N: Brief descriptive title}}

2. **Description language**: Match the language of the surrounding text
   - Persian text → Persian title: `{{IMG_1: نمودار چرخه قلبی}}`
   - English text → English title: `{{IMG_1: Cardiac cycle diagram}}`

3. **Description style**: Keep brief but clearly identifying
   - Good: `{{IMG_1: ساختار آناتومیکی کلیه}}`
   - Good: `{{IMG_2: Cross-section of the heart}}`
   - Bad: `{{IMG_1: This image shows a very detailed anatomical diagram of...}}` (too verbose)

4. **Only mark content images**: figures, diagrams, charts, photos, medical images, illustrations, graphs

5. **Do NOT mark**: decorative elements, page borders, logos, watermarks, background patterns

6. **Image numbering**: The starting number will be specified per page. Follow it sequentially.
